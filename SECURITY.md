# Security Policy

## Supported line

The supported line is the adopted SACS v1.0.0 constitutional and implementation baseline while this project remains in release preparation.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub’s private vulnerability reporting or security-advisory channel for this repository when enabled. If private reporting is not enabled, contact the repository owner privately through an authenticated GitHub channel and include only the information needed to reproduce and coordinate the issue.

This project does not operate a bug-bounty program.

## Scope

Security reports may include credential exposure, unsafe release packaging, dependency vulnerabilities, integrity or provenance failures, authority-boundary bypasses, or behavior that causes the implementation to exceed its documented scope. Internal conformance tests do not constitute external verification.
